# Schulrecht-Kompass Thüringen

Nachschlagewerk zum Schulrecht in Thüringen für Lehramtsanwärter:innen, Lehrkräfte und Fachleitungen.
Jeder Eintrag besteht aus Kurzantwort, wörtlichem Normzitat mit Fundstelle und Fassungsstand und einem Praxishinweis.

- 152 Einträge in elf Modulen, 34 Übungsfälle, Quiz, Lernkarten, 16 Kopiervorlagen, 22 Normtexte im Volltext
- Volltextsuche mit Alltagsbegriffen, Update-Radar für offene und ungeklärte Punkte
- eine einzige HTML-Datei, läuft offline im Browser, ohne Konto, ohne Server

**Aufrufen:** https://ufrefat-svg.github.io/schulrecht-kompass/

Nichtamtliche Arbeitshilfe, ersetzt keine Rechtsberatung. Stand Oktober 2026.

Von Uli Frefat · Lehrer · Fachleiter Musik und Doppelfach Musik. Gesetzes- und Verordnungstexte sind amtliche Werke (§ 5 UrhG).
Die Farbwelt lehnt sich an das Erscheinungsbild des tlv thüringer lehrerverband an; das Projekt ist kein Angebot des tlv, sein Logo wird nicht verwendet.
